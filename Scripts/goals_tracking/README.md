# Разбор видео Goals и анализ автотестов

**Трекинг видео Goals** (стандартная боковая камера):
- `cam.py` — модель камеры. Она снята по центральному кругу: f=3184 px при 2560, наклон 26.9°, высота 22.7 м. Там же проекция пиксель→газон и вид сверху.
- `detect.py` — поиск игроков (белые/тёмные) и мяча на кадре.
- `track2.py <video> <out.json>` — трекинг длинной записи в любом разрешении. Кадры с другой камерой отбрасываются, X привязывается к средней линии.
- `analyse2.py <out.json>` — метрики: открытые адресаты, прессинг, пасы, скорости.
- `track.py`, `anchor.py`, `analyse.py` — первая версия для 0702(19).mp4.

**Анализ логов автотестов игры** (запускается с `-ExecCmds="mf.Trace 1, ..."`):
- `kickanal.py`, `dribanal.py`, `recvanal.py`, `shotanal.py`, `anal.py`.

**Вспомогательное:**
- `ue.py` — выполнить Python в открытом редакторе (remote execution).
