# Мини-футбол 5×5 — прототип на Unreal Engine

Минимальный играбельный прототип мини-футбола 5 на 5 (4 полевых + вратарь).
Только геймплейное ядро: без меню, графики и звука.

## Что входит в прототип

- **Поле 40×24 м** с разметкой (линии, центральный круг, штрафные, точки) и двое ворот 3×2 м. Всё строится из кода простыми мешами движка.
- **10 игроков-капсул** — 5 красных (вратарь оранжевый) и 5 синих (вратарь бирюзовый). Человек управляет одним красным (над ним жёлтый маркер), остальными — простой ИИ: ближайший к мячу бежит к нему, остальные держат позицию в расстановке 1-2-2.
- **Мяч** — аркадная физика: гравитация, отскоки от газона и бортов, трение качения, сетка ворот, удар с силой, направлением и закруткой.
- **Механики** — пас низом, пас в разрез, навес, удар с зарядом силы, изящный удар, удар с лёта и головой, рывок, укрывание мяча, финты, отбор, подкат, жокей, сдерживание, прессинг партнёром, смена игрока, выход вратаря.
- **Вратарь-ИИ** — стоит на линии ворот, предугадывает точку удара и отбивает мяч. Выходит на свободный мяч в штрафной, а у красных ещё и по удержанию Y.
- **Логика матча** — гол засчитывается триггером в воротах, когда мяч полностью пересёк линию. Счёт, таймер 60 секунд, сброс позиций через 2 секунды после гола, экран конца матча.
- **Камера** — почти изометрия сверху (наклон −55°, узкий FOV), плавно следит за мячом.

## Файлы

| Файл | Что внутри |
|------|------------|
| `Source/MiniFootball/Soccer.h` | Объявления всех классов и константы поля |
| `Source/MiniFootball/Soccer.cpp` | Вся логика: мяч, ворота, игрок и ИИ, контроллер, GameMode |
| `Source/MiniFootball/MiniFootball.Build.cs` | Зависимость от модуля `EnhancedInput` |

Классы:

- `ASoccerBall` — мяч.
- `ASoccerGoal` — ворота и триггер гола.
- `ASoccerPlayer` — игрок (ACharacter): управление человеком, ИИ полевого и вратаря.
- `ASoccerPlayerController` — ввод (Enhanced Input создаётся в рантайме, ассеты не нужны), переключение игроков.
- `ASoccerGameMode` — поле, спавн, счёт, таймер, камера, HUD.

## Пошаговая сборка

1. **Создать проект** → Unreal Engine 5.3+ → Games → Blank → **C++**, имя `MiniFootball`, без стартового контента.
2. **Положить код** → скопировать `Soccer.h` и `Soccer.cpp` в `Source/MiniFootball/` рядом с `MiniFootball.cpp`.
3. **Подключить Enhanced Input** → в `Source/MiniFootball/MiniFootball.Build.cs` в `PublicDependencyModuleNames` должен быть `"EnhancedInput"` (готовый файл лежит в репозитории).
4. **Собрать** → закрыть редактор, в Visual Studio / Rider собрать `MiniFootball Editor` (или правый клик по `.uproject` → Generate project files → Build). Затем открыть редактор.
5. **Проверить ввод** → Project Settings → Engine → Input → *Default Input Component Class* = `EnhancedInputComponent`, *Default Player Input Class* = `EnhancedPlayerInput`. В UE 5.1+ так стоит по умолчанию.
6. **Создать уровень** → File → New Level → **Basic** → удалить из уровня `Floor`. Свет и небо оставить. Сохранить как `Soccer`.
7. **Прикрепить режим игры** → Window → World Settings → *GameMode Override* = `SoccerGameMode`. Блюпринты не нужны: поле, ворота, мяч, игроки и камера создаются сами в `ASoccerGameMode::BeginPlay`.
8. *(Опционально)* Project Settings → Maps & Modes → *Editor Startup Map* и *Game Default Map* = `Soccer`, *Default GameMode* = `SoccerGameMode`.
9. **Play** → подключите геймпад Xbox или PlayStation (DualShock/DualSense на Windows — через Steam Input или DS4Windows) либо играйте с клавиатуры.

Все настройки баланса — константы в коде: размеры поля в `namespace Soccer`, скорости в `ASoccerPlayer`, физика мяча в `ASoccerBall`, камера в `ASoccerGameMode`.

## Управление (классическая схема FIFA)

Атака это или оборона, определяется в момент нажатия: у вашей команды мяч или нет.

### ⚽ Атака

| Действие | Xbox | PlayStation | Клавиатура |
|----------|------|-------------|------------|
| Движение игрока | Левый стик | Левый стик | WASD |
| Пас низом / головой | A | ✖ | Space |
| Удар / с лёта / головой (зажать — сила, отпустить — удар) | B | ⭕ | F |
| Пас в разрез (на ход) | Y | ▲ | E |
| Навес / длинный пас | X | ⬛ | Q |
| Рывок (спринт) | RT | R2 | Shift |
| Укрывание мяча корпусом | LT | L2 | Ctrl |
| Финт — щелчок правым стиком в сторону | Правый стик | Правый стик | Стрелки |
| Модификатор: RB + B — изящный закрученный удар, RB + правый стик — большой финт | RB | R1 | R |

### 🛡️ Оборона

| Действие | Xbox | PlayStation | Клавиатура |
|----------|------|-------------|------------|
| Переключение на ближайшего к мячу | LB | L1 | Tab |
| Переключение на игрока в направлении стика | Правый стик | Правый стик | Стрелки |
| Сдерживание / опека (удержание) | A | ✖ | Space |
| Обычный отбор / толчок | B | ⭕ | F |
| Подкат | X | ⬛ | Q |
| Жокей — лицом к мячу, приставным шагом | LT | L2 | Ctrl |
| Прессинг партнёром (удержание) | RB | R1 | R |
| Выход вратаря из ворот (удержание) | Y | ▲ | E |

### Прочее

| Действие | Геймпад | Клавиатура |
|----------|---------|------------|
| Новый матч | Start / Options | Enter |

Когда мяч получает ваш партнёр, управление автоматически переходит к нему, как в FIFA.

## Что проверить после запуска

- Забить гол: счёт растёт, появляется «ГОЛ!», через 2 с все встают на позиции, мяч в центре.
- Через 60 с появляется «МАТЧ ОКОНЧЕН», Start/Enter запускает новый матч.
- LB переключает капсулу (жёлтый маркер перескакивает).
- Удар по центру ворот вратарь отбивает, а удар в угол может пропустить.
- Мяч отскакивает от бортов и в ворота влетает только через створ.

## Упрощения прототипа

- Ауты и угловые не реализованы: поле окружено бортами, как в зале.
- Мяч не сталкивается с игроками физически. Приём, отбор и сейвы — логика по дистанции.
- HUD выводится через `GEngine->AddOnScreenDebugMessage`, поэтому в Shipping-сборке его нет.
