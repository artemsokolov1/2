# Мини-футбол 5×5 — прототип на Unreal Engine

Минимальный играбельный прототип мини-футбола 5 на 5 (4 полевых + вратарь).
Только геймплейное ядро: без меню, графики и звука.

## Что входит в прототип

- **Поле** — прямоугольник с разметкой и двое ворот.
- **10 игроков-капсул** — 5 красных и 5 синих. Одним управляет человек (геймпад/клавиатура), остальными — простой ИИ (бежать к мячу / держать позицию).
- **Мяч** — сфера с аркадной физикой: отскоки, трение, удар с силой и направлением.
- **Механики** — пас, удар, навес, пас в разрез, рывок, отбор, подкат, вратарь-ИИ на линии ворот.
- **Логика матча** — детект гола (триггер в воротах), счёт, таймер 60 секунд, сброс позиций после гола.
- **Камера** — изометрия сверху, плавно следит за мячом.

## Технологии

- Unreal Engine 5.x (C++)
- Enhanced Input (геймпад Xbox / PlayStation + клавиатура)

## Структура кода (план)

| Файл | Назначение |
|------|------------|
| `SoccerBall` | Мяч: физика, отскоки, трение, удары |
| `SoccerPlayer` | Игрок-капсула: управление, ИИ полевых и вратаря |
| `SoccerGameMode` | Поле, ворота, голы, счёт, таймер, сброс, камера |

## Управление (как в FIFA)

### ⚽ Атака

| Действие | Xbox | PlayStation |
|----------|------|-------------|
| Движение игрока | Левый стик (L) | Левый стик (L3) |
| Пас низом / головой | A | ✖ Крест |
| Удар / волей / головой | B | ⭕ Круг |
| Пас в разрез (на ход) | Y | ▲ Треугольник |
| Навес / длинный пас | X | ⬛ Квадрат |
| Рывок (спринт) | RT | R2 |
| Укрывание мяча корпусом | LT | L2 |
| Дриблинг / финты | Правый стик (R) | Правый стик (R3) |
| Модификатор финтов / изящный удар | RB | R1 |

### 🛡️ Оборона

| Действие | Xbox | PlayStation |
|----------|------|-------------|
| Переключение на другого игрока | LB (или правый стик) | L1 (или правый стик) |
| Сдерживание / опека | A | ✖ Крест |
| Обычный отбор / толчок | B | ⭕ Круг |
| Подкат | X | ⬛ Квадрат |
| Жокей (лицом к мячу) | LT | L2 |
| Прессинг партнёром | RB | R1 |
| Выход вратаря из ворот | Удержание Y | Удержание ▲ |
